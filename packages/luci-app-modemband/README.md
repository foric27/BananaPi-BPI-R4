# luci-app-modemband

Интерфейс LuCI JavaScript для пакета `modemband` на системах OpenWrt и ImmortalWrt 24.10. Приложение предоставляет веб-интерфейс для проверки состояния модема в реальном времени, просмотра информации о SIM-карте и сотовой сети, а также управления предпочтительными полосами LTE/5G для поддерживаемых 4G/5G модемов.

## Возможности

- Представления LuCI JS в разделе `Модем > Конфигурация модема`.
- Обзор модема в реальном времени с указанием производителя, модели, версии, IMEI, состояния, питания и основного AT-порта.
- Отображение информации об операторе, регистрации, текущей ячейке, регионе, мощности сигнала, RSRP, RSRQ, SINR, TAC, CID, PCI и ARFCN.
- Сбор температуры и напряжения модуля через AT-команды, если модем это поддерживает.
- Карточка информации о SIM-карте со статусом, ICCID, IMSI, EID, оператором, типом SIM и экстренными номерами.
- Страницы выбора полос LTE, 5G SA и 5G NSA, поддерживаемые инструментом командной строки `modemband`.
- Страница конфигурации для параметров перезапуска WAN, перезапуска модема, AT-команды перезапуска, порта связи и выбора шаблона модема.
- Стили для светлой и темной темы, совместимые с Argon для страниц LuCI OpenWrt 24.10.
- Файл перевода на упрощенный китайский в `po/zh_Hans/modemband.po`.

## Зависимости

Пакет объявляет следующую зависимость LuCI:

```make
LUCI_DEPENDS:=+modemband
```

Страница обзора может использовать следующие инструменты времени выполнения, если они доступны и разрешены ACL rpcd:

- `/usr/bin/modemband.sh`
- `/usr/bin/loaded.sh`
- `/usr/bin/mmcli`
- `/usr/bin/sms_tool`

Для получения данных в реальном времени рекомендуется использовать `ModemManager`. Без него страница всё равно загружается, но некоторые поля состояния могут отображать `--` или недоступное состояние.

## Источники информации о SIM-карте

Карточка информации о SIM-карте читает данные из двух источников:

1. Объект SIM-карты ModemManager, используя `mmcli -i <sim-index> -J`, когда модем предоставляет путь к SIM-карте.
2. Резервный вариант через AT-команды с помощью `sms_tool`:
   - `AT+CPIN?` для PIN-кода SIM или состояния готовности.
   - `AT+QCCID` и `AT+CCID` для ICCID.
   - `AT+CIMI` для IMSI.

Если модем сообщает `sim-missing`, карточка явно отображает `SIM-карта не обнаружена` вместо неактивного состояния. Если SIM-карта вставлена, но ICCID или IMSI остаются пустыми, убедитесь, что выбранный AT-порт правильный и прошивка модема разрешает эти AT-команды.

## Сборка

Из сборочного окружения OpenWrt с установленным фидом LuCI:

```sh
./scripts/feeds update luci
./scripts/feeds install luci-app-modemband
make package/luci-app-modemband/compile V=s
```

Для полной сборки образа выберите или включите пакет в конфигурации сборочного окружения OpenWrt как обычно.

## Установка

Установите сгенерированный пакет на роутер:

```sh
opkg install luci-app-modemband_*.ipk
```

После установки при необходимости перезагрузите кэши LuCI и rpcd:

```sh
rm -rf /tmp/luci-modulecache
rm -f /tmp/luci-indexcache
/etc/init.d/rpcd reload
```

Страница доступна по адресу:

```text
Системное меню: Модем > Конфигурация модема
Путь LuCI: /cgi-bin/luci/admin/modem/luci-app-modemband/overview
```

## Конфигурация

Секция UCI по умолчанию хранится в `/etc/config/modemband`:

```text
config modemband
        option iface 'wan'
        option wanrestart '0'
        option modemrestart '0'
        option notify '0'
```

Основные параметры управляются через страницу конфигурации LuCI:

- Имя интерфейса WAN для перезапуска соединения.
- Перезапуск WAN после изменения полос.
- Перезапуск модема после изменения полос.
- Необязательная AT-команда для перезапуска модема.
- AT-порт связи, используемый приложением.
- Шаблон модема, назначенный по текущему Vendor и Product ID.

## Проверки времени выполнения

Используйте эти команды на роутере для проверки среды выполнения:

```sh
mmcli -L -J
mmcli -m 0 -J
mmcli -m 0 --location-get -J
sms_tool -d /dev/ttyUSB2 at 'AT+CPIN?'
sms_tool -d /dev/ttyUSB2 at 'AT+QCCID'
sms_tool -d /dev/ttyUSB2 at 'AT+CIMI'
```

Замените `/dev/ttyUSB2` на AT-порт, настроенный в приложении, если ваш модем использует другой порт.

## Валидация

Для синтаксической проверки фронтенда во время разработки:

```sh
node --check htdocs/luci-static/resources/view/modem/overview.js
node --check htdocs/luci-static/resources/view/modem/blte.js
node --check htdocs/luci-static/resources/view/modem/blteconfig.js
```

Рекомендуемые ручные проверки после установки или горячего развёртывания изменений:

- Откройте страницу обзора и убедитесь, что карточка модема отображается.
- Убедитесь, что карточка информации о SIM-карте показывает либо обнаруженные данные SIM-карты, либо чёткий статус отсутствия SIM-карты.
- Убедитесь, что поля сигнала, температуры, напряжения, региона и текущей ячейки не блокируют отрисовку страницы, когда команда бэкенда недоступна.
- Откройте настройки полос и убедитесь, что выбранные полосы LTE/5G загружаются корректно.
- Откройте конфигурацию и убедитесь, что AT-порт и параметры перезапуска могут быть сохранены.

## Примечания

- Приложение ориентировано на JavaScript-представления OpenWrt и LuCI стиля 24.10.
- ACL-разрешения намеренно ограничены инструментами и путями, необходимыми для работы интерфейса.
- Некоторые поля модема зависят от поддержки прошивкой. Отсутствие поддержки AT должно приводить к `--` или недоступному состоянию, а не блокировать страницу LuCI.
- Если LuCI продолжает показывать устаревший код фронтенда после развёртывания, очистите `/tmp/luci-modulecache`, удалите `/tmp/luci-indexcache` и принудительно обновите кэш браузера.
